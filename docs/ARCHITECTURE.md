# Phase 1 工程与安全决策

## 交付范围

这是可运行的 Web/PWA 与 Capacitor 接入基础。真实媒体读取、扫描、端侧模型、原生数据库与原图操作不属于本阶段。

## 数据路径

1. 应用启动：读取本应用命名空间的主题与示例收藏；没有记录时，在内存中生成示例。
2. 照片浏览：只读取 `/art/*.svg`；不会访问图库、文件系统或远程主机。
3. 收藏：先写本地存储，成功后更新 UI；失败显示错误，不伪造保存成功。
4. 搜索：对已经加载的本地示例字段匹配，不发送查询或图片。
5. 清理：只浏览手工设定的相似组；“保留”是会话状态，不执行删除。
6. 清除：二次确认后写入示例隐藏状态；不枚举或删除其他站点键，不访问原图。

## SQLite 模型

| 表                 | 用途                             | 约束                             |
| ------------------ | -------------------------------- | -------------------------------- |
| schema_migrations  | 版本记录                         | 版本唯一                         |
| photos             | 本地资源引用、尺寸、字节数、收藏 | 资源 ID 唯一，尺寸为正，收藏 0/1 |
| albums             | 手动/分类相册                    | 类型枚举                         |
| album_photos       | 相册与照片关联                   | 复合主键、外键                   |
| photo_tags         | 手动/示例/端侧标签               | 禁止 cloud 来源、复合主键        |
| cleanup_candidates | 建议组与人工审核状态             | 原因及状态枚举、默认 pending     |

外键的级联仅作用于本地元数据，不是对系统相册的删除权限。v1 不保存原始图片字节、GPS 坐标、云凭据。后续迁移需要增加新的版本，不能直接改写已投产的 v1。

## 技术选择

Vue 3 + TypeScript + Vite、Pinia、Vue Router Hash 历史；Hash 路由适合静态预览与后续 Capacitor 容器。全部页面为本地代码分块，由生产 Service Worker 一并预缓存。主题支持系统变化事件，偏好只保存在本地。

不引入真实照片导入入口：按钮明确说明 Phase 2 边界；不请求隐藏权限。不引入后端、生产数据库、账号、网络 AI SDK。默认隐私策略被冻结，不能通过设置页打开上传或删除。

## 已知限制

- 示例是插画，不是真实用户照片；不会展示虚构的扫描进度或实际存储释放数字。
- 本地匹配不是语义 AI，示例相似组不是算法检测结果。
- localStorage 与 PWA Cache 不具备应用层加密；SQLite 驱动尚未接入。
- 真正原生安全能力、生物识别、Android/iOS 安装包、相册权限兼容与真机验证留待后续阶段。
- Service Worker 仅在 HTTPS 或可信回环地址生效；首次缓存完成前离线无法首次加载。

## 开发依赖修复

Capacitor CLI 8.5.3 间接使用的 `xcode` 默认依赖旧版 `uuid`，npm 审计报告其缓冲区边界漏洞。工程通过局部 `overrides.xcode.uuid = 11.1.1` 固定到已修复且仍提供 CommonJS 的版本；已验证 `xcode` 的 `generateUuid()` 调用能生成正确的 24 位标识符。该依赖仅用于开发工具，没有进入浏览器照片服务。以后升级 CLI 时应复查并移除此临时覆盖。
