## 环境

- Android 7–12 / API 24–32：旧版只读图片存储授权。
- Android 13 / API 33：READ_MEDIA_IMAGES 授权。
- Android 14+ / API 34+：完整、有限图片访问与范围缩减。
- iOS 15+：PhotoKit 未决定、拒绝、完整、有限、受限状态。
- 空相册；含 101、401 张本地图片的相册；仅 iCloud 未下载的图片；包含损坏/已删除资源。

## 必测行为

| 步骤                         | 预期                                                                       |
| ---------------------------- | -------------------------------------------------------------------------- |
| 首次启动                     | 无系统权限弹窗、无扫描；自动扫描关闭；不显示浏览器示例                     |
| 点击连接、取消说明           | 无系统权限请求，数据库无照片索引                                           |
| 继续授权、拒绝               | 无扫描、无照片展示；可打开系统设置                                         |
| 完整授权                     | 分页索引本机图片，真实进度，完成后一次展示；无上传                         |
| 有限授权                     | 仅选定照片；系统设置缩小范围后返回应用，不显示不可访问标题或缩略图         |
| 扫描中取消/切后台            | 丢弃暂存，上次完整索引保留；界面照片和缩略图移除                           |
| 扫描中系统收回权限           | 不提交暂存；返回应用后清除本地设备索引                                     |
| 扫描中杀进程、重启           | 清理中断暂存，不展示半次扫描结果                                           |
| 本机新增/修改/删除照片后再扫 | 更新索引、移除失效元数据、保留存续照片收藏、标签和相册关系；不改变系统原图 |
| 开启自动扫描、重启/返回前台  | 已授权时自动扫描；关闭后不再自动扫描；切后台取消                           |
| 401 张照片                   | 分页与可见区域缩略图正常，允许取消；标识访问校验分 200 条批次              |
| iCloud 无本地缩略图          | 显示不可用预览，不主动下载原图                                             |
| 收藏、重启                   | 收藏仍在；不修改系统相册收藏                                               |
| 清除本地照片索引             | 二次确认；清除索引/收藏/相册/标签/扫描设置；自动扫描关闭，原图保留         |
| 断网/飞行模式重启            | 本地照片和索引可用，不依赖网页服务器                                       |
| APK 权限/备份检查            | 无 INTERNET、相机、位置、视频、写入权限；关闭备份与设备迁移                |
| iOS 备份检查                 | SQLite 在排除备份的 Library/NoCloud；无照片原图/缩略图磁盘副本             |

## 构建与检查命令

```sh
npm ci
npm run build
npm run cap:sync
npm run cap:check
```

Android：`cd android` 后 `gradlew.bat :app:assembleDebug :nobi-photo-library:lintDebug`（Windows），或 `bash gradlew ...`（macOS/Linux）。安装 Debug APK 后按矩阵验证，记录设备型号、系统版本、授权范围、步骤和结果。

iOS：在 macOS 用 Xcode 打开 `ios/App/App.xcodeproj`，配置签名后安装到测试设备。也可先执行 README 中的模拟器无签名编译命令。当前仓库提供 macOS CI 编译作业，但尚未推送/运行远程 CI。

测试结果必须区分：实际执行、未执行、模拟桥接测试。严禁将 JS mock 的权限结果写成系统权限真机测试通过。
