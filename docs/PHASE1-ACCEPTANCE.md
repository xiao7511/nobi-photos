## 可操作功能

- 照片：12 张本地示例插画、日期分组、六种筛选、升降序、两种密度、详情、收藏与刷新恢复。
- 分类：四个标签分类、收藏相册、展开浏览。
- AI 搜索：本地标题/分类/地点/标签关键词，多个空格分隔词取交集；**尚无语义 AI**。
- 清理：预设相似组、会话内“全部保留”，不提供删除按钮，不伪造真实空间释放数字。
- 我的：本地访客、照片/收藏统计、外观设置、隐私入口。
- 隐私中心：数据流与权限说明，清除/恢复示例，说明本地元数据未加密。

## 明确的阶段边界

1. 当前照片全为随包插画，未读取真实相册。连接本机相册入口只解释后续阶段边界。
2. SQLite 是已验证的模型及连接接口；运行时使用 localStorage 示例元数据仓库，**未接入原生 SQLite 驱动**。
3. 搜索是本地字段匹配，相似组是手工示例；未启用云端或端侧 AI。
4. 未生成 Android/iOS 原生工程或安装包，未开展真机相册授权与读取测试。
5. PWA 离线要求首次成功加载并完成缓存；开发服务器不提供该生产离线行为。
6. 本地元数据没有应用层加密，浏览器缓存也不是保险箱；已在界面清楚说明。
7. 所有实现与安装均限定本项目；下载的是开发依赖，没有向外发送用户照片。
8. 当前会话没有切换模型/推理强度的控制工具，因此未声称模型已被切换，也没有改写全局模型设置。

## 验收方式与停止点

运行 `npm run dev` 进行界面验收，或构建后 `npm run preview` 验证离线功能。默认服务仅监听本机回环地址。

**Phase 1 已完成，到此停止。等待用户验收；不会自动进入 Phase 2。** 下一阶段的原生照片读取、权限、SQLite 驱动与自动扫描均未启动。
