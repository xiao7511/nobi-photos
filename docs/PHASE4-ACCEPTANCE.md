日期：2026-10-21（Asia/Shanghai）。版本：0.4.0。基线：Phase 3 提交 `be3974e`，开始时工作区干净。Phase 3 已由用户验收；本阶段范围“批量整理＋组合搜索，并补 Android 权限与生命周期验证”已由用户确认。

## 功能与数据边界

| 项目         | 实现                                                                                                            |
| ------------ | --------------------------------------------------------------------------------------------------------------- |
| 多选         | 照片页与搜索结果逐张选择、全选当前结果、清空与退出；每次最多 500 张；切换筛选、权限变化与进入后台时清理失效选择 |
| 批量收藏     | 加入或取消本应用的收藏，不修改系统收藏                                                                          |
| 批量标签     | 添加/移除填写的手动标签，保留其他标签；大小写去重，逐张校验 20 标签上限                                         |
| 批量相册成员 | 加入或移出已有自建相册，保留其他成员；不移动、复制或删除系统照片                                                |
| 整批保存     | 预先校验全部所选照片；原生用单个 SQLite 事务，浏览器用单次 localStorage 写入；任一写入失败全部回滚              |
| 组合搜索     | 关键词、日期、自建相册、精确手动标签、收藏、横/竖/方图取交集；多标签取交集、忽略大小写                          |
| 搜索一致性   | 结果随图库/整理数据重新计算；移除匹配标签、取消收藏或权限缩小后不保留过期结果                                   |
| 隐私         | 搜索条件与多选仅在当前页面内存中；不写入历史、网址或数据库；原生批量写入前复查当前授权和资源可访问性            |

日期包含首尾两天，按索引中 `takenAt` 的日期部分筛选，不声称能重建原图拍摄时区。所有条件在按下“搜索”后应用。精确手动标签与原有关键词搜索分开，关键词仍匹配已加载的标题、日期、分类、地点与标签。没有接入端侧语义 AI、云端 AI 或历史搜索。

复用 SQLite schema v2 与现有浏览器键，无新依赖、数据库连接或权限。没有批量删除原图接口。新相册仍在分类页创建。

## 原生补验

最终 0.4.0 APK 已在专用 `nobi_photos_test` Android 14 AOSP / API 34 模拟器完整通过以下真实系统集成验证。全部 101 张图片均由脚本生成，不读取私人相册。

| 场景               | 实际结果                                                                                            |
| ------------------ | --------------------------------------------------------------------------------------------------- |
| 系统照片权限       | 首次为 prompt，实际点击系统拒绝与允许全部；不是 mock 或 ADB 直接授予权限                            |
| 原生基础回归       | MediaStore 101 张分页索引、原生 SQLite 101 条、JPEG 缩略图与收藏刷新恢复                            |
| Phase 3 回归       | 自建相册、手动标签 SQL 查询、本地相似分析 101 张完成                                                |
| Phase 4 批量与搜索 | 实际界面选择两张、批量添加标签；SQLite 查询得到两条，精确标签搜索展示两张                           |
| 切后台/返回        | Home 键进入后台后页面照片为 0；返回前台复查权限并恢复两张搜索结果                                   |
| 断网冷启动         | 开启飞行模式并关闭 Wi-Fi，核对系统开关；强制停止进程后重新启动，101 张索引可用且批量标签仍为两条    |
| 撤销权限           | 通过 ADB 撤销测试应用两项照片读取权限后重新启动；页面为 0 张，SQLite 照片计数 0，批量手动标签计数 0 |
